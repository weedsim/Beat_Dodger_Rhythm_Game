# 폭주밴드: 소음주의보 (Noise Alert)

**비트가 곧 무기다.**  
4인조 밴드가 각자 라인을 맡아 리듬 타이밍에 맞춰 좀비 웨이브를 격파하는 **캐주얼 협동 리듬 디펜스 액션** 게임입니다.

---

## 게임 소개
네온으로 빛나는 네오 시티에 좀비 웨이브가 몰려옵니다.  
플레이어는 드럼/일렉/베이스/키보드 중 하나를 선택해 담당 라인을 방어하며, **정확한 박자 입력으로 더 강한 공격과 더 화려한 연출**을 만들어냅니다.  
단순히 내 라인만 처리하는 것을 넘어, 팀원과 타이밍을 맞춰 발동하는 **협동 콤보(공통 비트)**가 공략의 핵심입니다.

---

## 핵심 재미 (Core Fun)
- **원버튼 리듬 액션**: 복잡한 조작 대신 “타이밍”에 집중
- **협동 콤보**: 인접 라인의 “공통 비트”를 동시에 맞춰 합공 발동
- **3D 타격감/연출 보상**: 콤보가 쌓일수록 카메라/이펙트가 강화되는 손맛

---

## 코어 루프 (Core Loop)
1. 매칭/방 입장
2. 악기(역할) 선택
3. 곡(스테이지) 시작 → 노트/웨이브 진행
4. 판정(Perfect/Great/Good/Miss)에 따라 처치/점수/콤보 누적
5. 협동 콤보로 대규모 웨이브 돌파
6. 클리어/실패 판정
7. 결과(팀 총점/랭크) 확인 → 재도전/다음 곡

---

## 게임 플레이 핵심 시스템
### 3D 라인 디펜스 + 리듬 입력
- 전방에서 진입하는 적이 **Attack Zone**에 들어오면 리듬 타이밍 입력으로 처치
- Perfect일수록 효율/점수/연출이 강화되는 보상 구조

### 협동 콤보(공통 비트)
- 인접한 두 라인 사이에 “공통 비트”가 생성
- 두 플레이어가 **동시에** 타이밍 적중 시 합공 발동(광역 레이저/거대 음파 등)

### 적 패턴(예시)
- **탱커**: 연타(정박) 또는 협동 콤보가 필요한 중형 적
- **러너**: 빠른 구간에서 급가속해 침투하는 적
- **변칙**: 엇박/분할 박자, 처치 시 라인 디버프 등 변칙 행동

---

## 플랫폼 / 조작
- **플랫폼**: PC / 모바일 / 콘솔 (크로스플레이)
- **조작**: 플랫폼별 단일 입력(1Key/1Button/Touch) 중심  
  - PC: 키보드(예: Space) 또는 마우스  
  - Mobile: 터치  
  - Console: 패드(예: A)

---

## 결과 및 랭크
- **팀 총점 = 플레이어 점수 합산**
- 랭크: **S / A / B / C / F**
